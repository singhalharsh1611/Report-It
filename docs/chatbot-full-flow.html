7) Direct message without selecting any option (actual current behavior)

Current code does not allow direct message in intro.
  • Initial step is intro (line 22)
  • When step is intro, only the 3 action buttons are shown (425–449)
  • Text input form is hidden in intro (451 condition)
  • Therefore user must click one of: Report Issue / Track Issue / Others first.

No automatic intent classification from a free-typed intro message exists in this file.

9) End-to-end Summary (one-liners)

  • Report Issue: button → describe issue → Gemini extracts title/desc/category → location fetch → image upload → POST issue → returns issueId.
  • Track Issue: button → enter issueId → backend fetch by nanoid → Gemini formats readable status message.
  • Others: button → free civic query → conversation prompt + history → Gemini answer + route guidance links.
  • Direct intro typing: not enabled in current UI state logic.
